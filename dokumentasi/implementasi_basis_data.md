# 4.3.2 Implementasi Basis Data

Implementasi basis data dilakukan pada PostgreSQL yang dikelola melalui layanan Supabase dengan membuat 9 tabel utama yang saling berelasi menggunakan primary key bertipe UUID dan foreign key dengan constraint ON DELETE CASCADE atau SET NULL untuk menjaga integritas data. Struktur database dirancang dengan pemisahan yang jelas antara tabel **queue_tickets** untuk manajemen antrian dan tabel **visits** untuk registrasi kunjungan, dimana satu tiket antrian dapat menghasilkan nol atau satu kunjungan melalui relasi foreign key queue_ticket_id dengan kardinalitas 1:0..1. Relasi antar tabel lainnya meliputi one-to-many antara patients dengan visits (1:N), many-to-one antara visits dengan poli, doctors, dan penjamin (N:1), serta many-to-many antara patients dengan penjamin melalui tabel perantara patient_penjamin. Implementasi dilengkapi dengan database functions untuk automasi logic bisnis seperti generate nomor antrian sequential per hari dengan auto-reset, load balancing distribusi antrian ke loket, dan validasi kuota poli serta dokter sebelum registrasi. Database triggers diterapkan untuk auto-generate nomor registrasi dengan format tertentu saat insert data kunjungan, sementara indexes dibuat pada kolom yang sering di-query seperti status antrian, tanggal kunjungan, dan relasi poli-dokter untuk optimasi performa query. Dengan implementasi ini, sistem dapat mengelola alur dari pengambilan antrian, pemanggilan pasien, hingga registrasi kunjungan secara efisien dan terintegrasi.
